# 文章转视频 —— 设计说明（2026-10-17）

## 这个功能解决什么

用户手里有一篇文章，想要一条能直接发的竖屏短视频。系统负责：读懂文章 → 抽数据并核对出处 →
把数据画成图表 → 写解说、选画面、配音、渲染。

入口在快捷按钮条「一键复刻爆款视频」右侧，名称「文章转视频」。

## 三条链路的关系

「文章转视频」没有另起一条视频管线，它把文章变成**素材 + 创作要求**后交给既有管线：

```
文章（链接/文档/正文）
  → 图表 PNG（程序绘制）+ 原文配图
  → materials 数组（图表在前）
  → runVideoPlanStage（风格 / 旁白 / 配音 / DSH 分镜）
  → 方案确认 → runVideoPipeline（Remotion + 字幕 + BGM）
```

复用点与不复用点：

| 环节 | 复用既有实现 | 本功能新增 |
| --- | --- | --- |
| 正文提取 | `extractHtmlMainText`、`extractDocumentText` | `article-source.ts` 归一化三种来源 |
| 视频编排 | `runVideoPlanStage` / `runVideoPipeline` | 只组装 `materials` 与 `requirement` |
| 出片路由 | `gen-video`（带 `planToken` 即 resume） | 无 |
| 数据模型 | `VideoPlan`（`draftJson` 存全部方案） | `draftJson.article` 可选扩展 |
| 图表 | 无 | `article/chart-render.ts` |
| 数据溯源 | 无 | `article/analyze.ts` 的 `verifyChartSpecs` |

**为什么图表当素材就能自动上屏**：`normalizeMaterials` 按扩展名判定 `.png` 为图片 →
进 `insightImages` 识图（图表的标题与数值会被识别成语义）→ `planStoryboard` 让 DSH
「把对的图放在对的句子上」→ `bindStoryboardPaths` 按顺序强制绑定真实素材。
所以渲染层一行没改。

**为什么要把图表放在 materials 最前面**：用户没配 vision 模型时 `insights` 为空，
分镜退化为按顺序轮播。若图表不在最前，观众先看到的会是原文配图。

## 溯源闸门：「数据不编造」是程序保证的

产品要求：图表上的数字只能来自文章或联网搜索，**禁止编造**。prompt 约束不可靠，
所以真正的执行点在 `verifyChartSpecs`：

1. 分析阶段强制模型为每个数值输出 `sourceQuote`（原文逐字片段）与 `sourceKind`。
   **没有 `sourceQuote` 的数值直接不收**（`parseDataPoints`）。
2. 校验：
   - `article` 源 → 归一化后 `normalizedArticleText.includes(sourceQuote)`
   - `search` 源 → `sourceUrl` 必须在本次 `searchWeb` 命中集内，且 `sourceQuote` 命中该条 snippet
3. 归一化（全角转半角、去空白、引号统一）避免模型微调一个标点就被误判为编造。
4. 校验不通过的数值，其关联图表**强制降级为 `info` 图卡**（图卡不渲染数值），
   标 `downgraded: true` 与原因，并在方案面板如实展示。

效果：模型幻觉出的数字**不可能出现在画面上**，只会被降级成不含数值的图卡。

## 六类图表

| kind | 图形 | payload |
| --- | --- | --- |
| `bar` | 柱状图（2~6 项） | `{items:[{label,value}], unit?, note?}` |
| `line` | 折线图（≤3 系列 × ≤8 点） | `{series:[{name,points:[{label,value}]}]}` |
| `pie` | 环形饼图（2~5 块） | `{items:[{label,value}], unit?}` |
| `kpi` | 数字卡（值 + 单位 + 增幅徽章） | `{value, unit?, label?, delta?, deltaLabel?}` |
| `timeline` | 竖向时间线（2~6 步） | `{steps:[{label,title,detail?}]}` |
| `info` | 图卡（不需要真实数值） | `{headline?, bullets[], footer?}` |

画布固定 **1080×1920**，与 `remotion/src/vertical/schema.ts` 的 `Storyboard.width/height`
一致，渲染时 `objectFit: cover` 满幅不裁切。

**底部 400px 刻意留白** —— 成片会烧录字幕，内容画到 1520px 为止。来源脚注画在
1554px 处，把「可溯源」这件事直接印在画面上。

主题配色取自 `remotion/src/theme.ts` 的 9 套主题（`primaryColor` / `chartColors` /
`backgroundColor` / `textColor` / `mutedTextColor`），保证图表与成片同源。
未知 themeKey 由 `resolveTheme` 回落，不报错。

字体：独立族名 `AiWorkerChart`（不与 `image-gen.ts` 的 `AiWorkerCover` 混用），
候选列表**只含免费可商用字体**（Noto Sans SC，SIL OFL 1.1）——
历史踩坑：`simhei`（中易授权）与 `msyh`（方正授权）都不是免费可商用。

## 耗时与调用次数

| 环节 | 次数 | 说明 |
| --- | --- | --- |
| 文章理解 + 数据抽取 | 1 次 `chatComplete(chat)` | 单次产出摘要/要点/数据点/图表方案，不拆三次 |
| 联网搜索 | **0 或 1 次** | 仅当 `dataGaps` 非空（或数据 <3 条）**且**用户勾选允许联网 |
| 搜索结果抽取 | 0 或 1 次 `chatComplete(chat)` | 与搜索配对，全流程最多 1 次 |
| 图表渲染 | 4~6 张 canvas | 单张 < 200ms |
| 图表张数上限 | 6 | `chartBudget = clamp(时长/10 + 2, 3, 6)` |
| 识图 | 复用 `insightImages` | **vision 无条数上限**，图表张数须自己控制 |
| 配音 + 分镜 | 管线内既有 | 规划阶段约 1~2 分钟，配音不可省（beats 来自 TTS 句级时间戳） |

文章正文进 prompt 前截断到 12000 字（`ARTICLE_TEXT_LIMIT`），避免超上下文；
正文本身不落库，只落摘要、要点与图表清单。

## 降级策略（全部如实告知用户，不静默）

| 情况 | 行为 |
| --- | --- |
| 数值无法溯源 | 该图降级为 `info` 图卡，方案面板标注「数据无法溯源，已降级」+ 原因 |
| 图表绘制抛错 | 该图改画图卡，`notices` 记「绘制失败（原因）」 |
| 联网搜索失败 | 捕获 `SearchError`，原因写入 `article.notices`，面板显示「联网补充没生效」 |
| 未勾选联网但有数据缺口 | 面板提示「未联网搜索，仅使用文章原有数据」 |
| 文章无可溯源数值 | 只出图卡，不出数据图 |
| vision 未配置 | 分镜按素材顺序轮播（图表在前已保证主角是图表），面板给出既有警告 |

## 安全边界

- URL 抓取的校验逻辑抽到 `src/lib/fetch-web-page.ts` 纯函数，知识库的 `fetch-url`
  路由改为调用它（传 `allowPrivateHosts: true` 保持其历史行为）。
  **文章转视频不传该开关**，因此默认拒绝环回与私网地址（SSRF 防护）。
- 所有模型调用走 `chatComplete({ userId, capability })`，只用**用户自己的 key**，
  不读 `process.env.*`（理由见 `src/lib/narration.ts` 文件头）。
- `src/lib/article/` 全目录**不 import prisma 写操作** —— 这是 OpenClaw spawn 的
  CLI（无数据库写权限）能安全复用它的前提。

## OpenClaw 接入（第二轮，本轮未做）

方案已定型，见仓库根目录的对话记录与本文件「三条链路的关系」一节。要点：

- `scripts/aiworker-video.mts` 新增 `--article-url / --article-file / --article-text /
  --allow-search`，三者互斥且至少一个；文章模式允许 `--materials` 为空。
- `--skip-plan` 必须读 `<workDir>/article-plan.json` 缓存，**不得重复调用 LLM 与搜索**，
  否则每次确认都要再等 1~2 分钟。
- `gen-video/from-cli` 的 `FromCliBody` 增加可选 `draft`，让图表清单能落库；
  缺 `draft` 时回退现有 7 字段拼装（向后兼容）。**路径穿越防护一行不改。**
- `buildVideoCapabilityBlock` 注入文章版命令签名与「文章模式不需要 `--materials`」的说明。

## 自测要点

1. `npx tsx` 跑一份假数据：真实 quote 应 `verified=true`；假 quote 与未命中 URL 应
   被降级为 `info`；图表 PNG 应全部生成且无「绘制失败」告警。
2. 端到端：三种来源各跑一条，确认方案面板出现图表清单、降级项显示原因。
3. 边界：数据无法溯源触发降级、联网搜索失败给出提示。
